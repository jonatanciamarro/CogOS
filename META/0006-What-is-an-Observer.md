# META-0006: What is an Observer?

## 1. The Question
What is the role of an "observer" within a cognitive system, and how does the act of observation affect the epistemic value of data?

---

## 2. Competing Theories

### Theory A: Passive Sensor (Objective Recorder)
* **Definition**: An observer is a passive interface that records objective facts from the environment without introducing bias or distortion.
* **Assumes**: Facts exist independently of observation. The observer is a transparent channel.
* **Predicts**: Multiple distinct observers monitoring the same event will produce identical datasets.
* **Testable By**: Pointing multiple static logging agents at a database and verifying that their logs match.

### Theory B: Relational Frame of Reference (Active Constructor)
* **Definition**: An observer is a cognitive frame of reference that constitutes data by drawing semantic distinctions based on its internal ontology and state.
* **Assumes**: Information does not exist in an objective state; it is generated by the relational interface between the environment and the observer's boundaries.
* **Predicts**: Two observers with different internal ontologies will generate divergent information structures from the same raw signal.
* **Testable By**: Exposing two LLM nodes with different system contexts to the same log and measuring the semantic distance between their generated summaries.

---

## 3. Evidence Matrix

| Phenomenon / Anomaly | Theory A (Passive Sensor) | Theory B (Relational Frame) |
| :--- | :--- | :--- |
| **Bit-level data replication** | Strong (exact copies are identical) | Moderate (only holds if the observers share an identical sensory ontology) |
| **Interpretive divergence** | Poor (treats divergence as system noise or software failure) | Strong (attributes divergence to difference in observer states) |
| **Prompt-engineering dynamics** | Poor (struggles to explain why minor prompt changes alter reasoning output) | Strong (views the prompt as adjusting the observer's coordinate system) |

---

## 4. Current Best Theory
**Theory B (Relational Frame of Reference)** is selected as the current best theory.

* **Justification**: In Cognitive Systems Engineering, we cannot assume an objective, observer-free view of data. How an organizational system interprets a customer signal, a market anomaly, or a code bug depends on the semantic frame of the observing node. We must explicitly version and track the "Observer State" in our primitives' metadata to guarantee epistemic traceabilty.
