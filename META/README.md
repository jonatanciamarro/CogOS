# META - Core Cognitive Questions

This directory compiles the ten fundamental ontological and physical questions about systems, meaning, and intelligence. Rather than hosting dogmatic answers, each document structures a competitive dialectic between competing theories, an evidence matrix comparing their performance, and a selection of the current best-performing candidate.

## Document Dialectic Template

Every file in this folder must adhere to the following structure:

1. **The Question**: The core query and its structural importance.
2. **Competing Theories**: 
   * **Theory A**: Definition, assumptions, predictions, and testable protocols.
   * **Theory B**: Contrasting explanation, alternative assumptions, and predictions.
3. **Evidence Matrix**: A structured table mapping the theories against empirical tests, anomalies, or logical constraints.
4. **Current Best Theory**: The theory selected as the baseline for CSE, with technical justification and operational bounds.
