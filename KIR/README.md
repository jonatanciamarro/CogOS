# KIR-0000: Knowledge Intermediate Representation (KIR)

## 1. Objective
To define the grammar and specifications of the Knowledge Intermediate Representation (KIR)—the substrate-independent language generated by the LKB compiler and executed by runtime platforms.

---

## 2. Cognitive Single Assignment (CSA)

KIR enforces **Cognitive Single Assignment (CSA)** at the compilation level. Parallel to SSA in compiler design, CSA demands that:

1. **Immutable Assignment**: A cognitive state node is assigned exactly once. Every update or belief revision generates a new, version-stamped node (e.g. `%bel_0`, `%bel_1`).
2. **Epistemic Traceability**: No historical state or observation is overwritten or deleted dynamically.
3. **Lineage Pathing**: Every compiled assertion contains a permanent lineage header linking back to its exact inputs:
   $$\forall \Psi \in \text{KIR}, \quad \text{Lineage}(\Psi) = \{\mathcal{O}, \mathcal{E}, \mathcal{T}\}$$
   Where $\mathcal{O}$ represents the observers, $\mathcal{E}$ the evidence nodes, and $\mathcal{T}$ the transformation processes.

---

## 3. KIR Grammar Specification

KIR represents the compiled graph using a declarative, relational intermediate syntax:

```text
%node_id = cse://[domain]/[type].[name] [confidence_score]
    = OPERATOR %dep_1, %dep_2, ...
    {
        teleology: "Reason for existence"
        lineage: %ancestor_1, %ancestor_2
    }
```

### Reference Operators:
* `OBSERVE`: Transforms a signal and context into a belief through an observer frame.
* `COLLAPSE`: Resolves a belief and verified evidence into stabilized knowledge.
* `RESOLVE`: Applies constraint satisfaction to evaluate competing hypotheses.
* `SUPERSEDE`: Marks a node as historically inactive, routing active pointers to a new version.

---

## 4. KIR Code Examples

### Perception Event:
```text
%sig_0 = cse://signal/SIG-901 [1.00]
%obs_0 = cse://observer/market_sensor [0.90]
%ctx_0 = cse://context/volatility_high [1.00]

%bel_0 = cse://concept/belief.volatility_spike [0.45]
    = OBSERVE %sig_0, %obs_0, %ctx_0
    {
        teleology: "Detect sudden changes in market volume"
        lineage: %sig_0
    }
```

### Knowledge Conversion (Epistemic Collapse):
```text
%ev_0 = cse://evidence/EXP-104 [0.85]

%kn_0 = cse://concept/knowledge.volatility_spike [0.81]
    = COLLAPSE %bel_0, %ev_0
    {
        teleology: "Coordinate system defense triggers"
        lineage: %bel_0, %ev_0
    }
```
