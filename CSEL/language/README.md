# CSEL - Cognitive Systems Engineering Language

CSEL is the formal declarative language of CSERS. It is designed to define substrate-independent cognitive structures (entities, relations, schemas, capabilities, and experiments) that compile down to optimized Knowledge Intermediate Representation (KIR).

---

## Language Architecture

The CSEL specification is divided into five core areas:

* **[CSEL/language/grammar.md](file:///c:/Users/WDAGUtilityAccount/Downloads/projeto/CSEL/language/grammar.md)**: Syntax rules, keywords, and parser tokens for scientific declaration.
* **[CSEL/language/type_theory.md](file:///c:/Users/WDAGUtilityAccount/Downloads/projeto/CSEL/language/type_theory.md)**: Cognitive Type Theory (CTT) type validation rules.
* **[CSEL/inference/](file:///c:/Users/WDAGUtilityAccount/Downloads/projeto/CSEL/inference/)**: Epistemic reasoning and arbitration rules.
* **[CSEL/std/](file:///c:/Users/WDAGUtilityAccount/Downloads/projeto/CSEL/std/)**: The standard library defining baseline primitives.
* **[CSEL/compiler/](file:///c:/Users/WDAGUtilityAccount/Downloads/projeto/CSEL/compiler/)**: Mapping rules from CSEL source to compiled KIR.
