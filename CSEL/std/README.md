# CSEL Standard Library (std)

This directory contains the standardized, built-in CSEL files defining the system's core types, operations, and primitive structures. Any compiled program imports these templates to guarantee CSERS compliance.

* **[observation.csel](file:///c:/Users/WDAGUtilityAccount/Downloads/projeto/CSEL/std/observation.csel)**: Standard definition for mapping signals to observations.
* **[evidence.csel](file:///c:/Users/WDAGUtilityAccount/Downloads/projeto/CSEL/std/evidence.csel)**: Structures representing empirical validation nodes.
* **[belief.csel](file:///c:/Users/WDAGUtilityAccount/Downloads/projeto/CSEL/std/belief.csel)**: Standard format for speculative belief states.
* **[knowledge.csel](file:///c:/Users/WDAGUtilityAccount/Downloads/projeto/CSEL/std/knowledge.csel)**: Schema for stable, validated knowledge.
* **[decision.csel](file:///c:/Users/WDAGUtilityAccount/Downloads/projeto/CSEL/std/decision.csel)**: Base structure for action gates.
