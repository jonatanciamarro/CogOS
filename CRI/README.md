# CRI-0000: Cognitive Participation Interface (CRI)

## 1. Objective
To define the formal interface that enables any Cognitive Actor (Human, LLM, Agent, Robot, Simulation, or Organization) to participate, observe, and contribute to the CSERS ecosystem.

---

## 2. The Cognitive Actor

A **Cognitive Actor** is any entity that processes information and interacts with the LKB. Every actor is registered in the graph as a specialized observer:

```text
cse://actor/[name]
```

To participate, an actor must expose its trust score, type signature, and execution capabilities.

---

## 3. Core Participation Methods

The CRI specifies six standard methods that actors must implement to interface with the knowledge graph:

### 1. `observe(Signal, Context) -> Observation`
* **Objective**: Capture and filter raw environmental signals, binding them to context and observer parameters.

### 2. `reason(TargetNode, Context) -> Inference`
* **Objective**: Execute reasoning, simulation, or search over LKB nodes, outputting predictions or state vectors.

### 3. `propose(ProposedPrimitive) -> ProposalEvent`
* **Objective**: Propose the creation of a new primitive, hypothesis, or relation in the LKB.

### 4. `test(Hypothesis, ExperimentProtocol) -> TestResult`
* **Objective**: Execute an experiment to validate a hypothesis, outputting evidence and confidence updates.

### 5. `modify(TargetNode, Operation) -> MutationResult`
* **Objective**: Propose structural changes (splits, merges, evolution) to existing nodes.

### 6. `learn(FeedbackSignal) -> UpdateReceipt`
* **Objective**: Evaluate decision outcomes against observations, adjusting local priority levels and trust weights.

---

## 4. Communication Channels

Actors interact with the compiled graph through formal input and output pathways:

### Input Channels (Writing to the Graph)
* **Observation Interface**: Ingestion of raw signals and sensory feeds.
* **Reasoning Interface**: Submission of inference proofs and logical bounds.
* **Governance Interface**: Voting on proposals, validation of constraints, and conflict arbitration.

### Output Channels (Reading from the Graph)
* **Prediction**: Subscribing to expected signals generated by active primitives.
* **Decision**: Accessing action gates triggered by epistemic collapses.
* **Explanation**: Extracting the trace lineage (CSA) of any stabilized knowledge node.
